# reguaeletronica-wokwi

Régua eletrônica com sensor ultrassônico HC-SR04 e Arduino Uno. Mede o tempo de ida e volta do pulso, converte para centímetros (duração / 58) e mostra o valor em displays de 7 segmentos controlados por registradores 74HC595.

Simulação: https://wokwi.com/projects/433473201354555393
